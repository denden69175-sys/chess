# Шахматы с новыми режимами

Кроссплатформенная шахматная игра на Unity: обычные шахматы против бота, путешествие во времени,
онлайн со своей армией, задания и сундуки с раскрасками. Подробный план лежит в документе проекта.

## Что уже есть

`src/Chess.Core` — ядро правил на C#. Библиотека собрана под `netstandard2.1` и C# 9, поэтому её
можно напрямую подключить к Unity, а позже и к серверу.

- Позиция, ходы, FEN (`Position`, `Move`, `Square`, `Piece`).
- Генерация легальных ходов со всеми правилами: шах, связки, рокировка, взятие на проходе,
  превращение пешки (`MoveGenerator`).
- Партия: проверка ходов, отмена хода, мат, пат, правило 50 ходов, троекратное повторение,
  недостаточный материал (`Game`).
- Бот: поиск альфа-бета с тремя уровнями сложности, работает и со своими армиями (`Bot`).
- Своя армия: бюджет 39 очков, ровно один король, до 16 фигур на двух первых рядах,
  рокировка только если король и ладья стоят на классических клетках (`Army`).

## Как запустить тесты

Нужен .NET SDK 8:

```
dotnet test
```

Тесты проверяют генератор ходов по эталонным perft-числам (стартовая позиция до глубины 4 и ещё
четыре известные позиции), а также правила партии и сборку армии.

## Unity-проект

Папка `unity/` — проект для Unity 2022.3.62f3. Откройте её через Unity Hub
(«Add» → «Add project from disk»), затем откройте сцену `Assets/Scenes/Main` и нажмите Play.

- Ядро правил подключено как локальный пакет (`unity/Packages/manifest.json` →
  `file:../../src/Chess.Core`), поэтому правила не копируются: Unity и тесты используют один код.
- Доска, фигуры и кнопки создаются из кода (`Assets/Scripts/ChessBoardView.cs`), так что игра
  запускается даже в пустой сцене.
- Можно играть за белых или за чёрных против бота трёх уровней, ходить перетаскиванием или
  двумя кликами, отменять ход. Пешка пока всегда превращается в ферзя.

Пример работы с ядром из своего скрипта:

```csharp
var game = new Game();
var move = game.FindMove(Square.Parse("e2"), Square.Parse("e4"));
if (move.HasValue)
    game.MakeMove(move.Value);
Debug.Log(game.Status);
```
